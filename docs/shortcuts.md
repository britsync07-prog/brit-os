# Keyboard Shortcuts - BritOS 7

Press ? anywhere to open the help overlay.

| Key | Action |
|-----|--------|
| ? | Toggle help overlay |
| Alt+F4 / Esc | Close focused window |
| Drag titlebar | Move window |
| Double-click icon | Open app |
| Ctrl+F5 | Hard refresh |
